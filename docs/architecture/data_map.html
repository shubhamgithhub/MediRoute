Three rules to remember

Edit only the ★ filesChange a speciality or a rule in the two maintained tables, then run the rebuild. Never edit a generated file.
One fact, one placeSpeciality names live only in specialties.csv; every rule only in specialty_mapping.csv. Tests fail on duplicates or unknown names.
Everything is regeneratablepython -m mediroute.data_generator.rebuild refreshes all generated files from raw/ and interim/.
