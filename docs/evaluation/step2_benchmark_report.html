Step 2 benchmark: today's engine vs design v2

Run 20261112_003122_step2 · 45 gold requests (5 strata) · oracle mode (the gold speciality and procedure go straight to Step 2) · grades are drafts from the hospitals' own websites, awaiting a human check of a sample.

Verdict: does the LLM add value in Step 2?

The LLM does not clearly earn its place here: S6 vs best non-LLM -0.03 NDCG@5 (rule: ≥ +0.05). Use the cheaper method unless the capability test below shows a safety gain.

Findings (read this first)

  1. Today's engine ranks best (NDCG@5 0.71). The v2 designs are not better: rules 0.70, embeddings 0.67, LLM 0.66. Only S6 vs today and S5 vs today are significant (p < 0.05), and both in today's favour.
  2. The LLM does not earn its place for capability matching on our data. On the 301 pairs with a readable website: rules precision 63% / recall 50% / 9 unsafe claims; embeddings 62% / 57% / 13; LLM 58% / 47% / 16. Same order with capability-focused weights (rules 0.69, embeddings 0.67, LLM 0.66 NDCG@5).
  3. Why: the bottleneck is the data, not the matching method. Every method reads the team sheet's short, unverified procedure lists (about 5 per hospital). Recall stops near 50% for all three because hospitals' websites confirm many procedures that our lists do not contain; better synonym understanding cannot find what is not listed, and more matches on unverified items mean more unsafe claims (worst for the LLM).
  4. Location tiers help suitability: S7 has the highest Capable@3 (93%: a capable hospital in the top 3 wherever it is) at the cost of strict-area metrics, the trade the TA asked for (suitability over location). Worth keeping as an option, not the default.
  5. Where AI can still add value: reading hospital websites to fill the procedure lists (the offline extraction in the design). That is now the step to test, because data coverage, not matching, limits accuracy.

Caveats: grades are LLM drafts from website snippets (48% low-confidence where sites block reading); 45 requests; a person must check a sample before these numbers are final.
